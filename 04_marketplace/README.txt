04 / Решения для задач — Сервисная платформа
Каталог услуг, фильтры и быстрый маршрут пользователя к нужной услуге.

Откройте index.html двойным кликом. Внутренние разделы работают как обычные отдельные HTML-страницы.

Функции: адаптивное меню, переходы между разделами, демонстрационная форма через mailto, страница запроса, внешние ссылки на sva-ov.ru и sva-protection.ru (в новой вкладке).
Дополнительно: поиск и фильтры в каталоге услуг. 

Возможная реализация на Tilda: собрать страницы стандартными/Zero Block блоками и при необходимости использовать HTML/CSS/JS в T123 или через head/body; Tilda поддерживает импорт HTML в Zero Block (со встроенным CSS), но JavaScript подключается отдельно, а результат может потребовать правок.

Примеры проектов взяты из документа заказчика; финальную публикацию следует согласовать.
