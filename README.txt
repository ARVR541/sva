СВА-МАРКЕТ — 4 независимые дизайн-концепции.

ОТКРЫТЬ: index.html в корне — обзор всех вариантов. Далее выберите вариант.
Каждая папка содержит 8 HTML-страниц, style.css, app.js и README.

01_corporate — светлый корпоративный сайт, деловая навигация, жизненный цикл.
02_editorial — типографический архитектурный editorial, отличная композиция и вертикальная навигация направлений.
03_control — темный инженерный интерфейс с конфигуратором модулей.
04_marketplace — сервисный каталог с поиском и фильтрами.

Контент базируется на предоставленном документе заказчика и действующих тематических сайтах. Это демонстрационный прототип, не коммерческий продукт. Не публиковать без согласования кейсов, юридических текстов, политики ПД и интеграции форм.

TILDA: HTML можно импортировать в Zero Block (CSS должен быть внутри HTML), а JS подключить отдельно через T123. После импорта может потребоваться доработка и настройка ссылок.
